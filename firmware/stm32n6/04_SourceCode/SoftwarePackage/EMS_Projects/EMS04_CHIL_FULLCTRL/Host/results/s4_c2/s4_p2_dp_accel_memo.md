## 2. DP 加速（J1+J2+J3，全部位级精确）

红线遵守：优化后输出与现实现**位级一致**（不是近似加速）。

| # | 机制 | 精确性论证要点 |
|---|---|---|
| J1 | **FLOOR 前缀合并**：lam_eff=max(raw_j+dlam_u, FLOOR)；dlam 升序 + IEEE RN 加法单调 ⇒ 全夹子集是前缀；前缀内轨迹逐位相同 ⇒ 跑一次代表轨迹（dlam=-1e300 强制全夹）+ max_j raw_j 保守判定成员；等值不触发 1e-15 改进 ⇒ first-min 语义自动保持（组胜出时 bu=组首）；oob 计数按组大小整数倍补回；空前缀回滚 rep 的 oob | 成员轨迹 ≡ 代表轨迹（子步归纳）；资格判定单调蕴含（误拒只慢不错） |
| J2 | **机组对对称崩塌**：两机组四状态按位相同（memcmp）且 nNi==2（双机 cmd/Pref 同源同值）⇒ 演化逐位相同 → 计算机组 0 并镜像；fuel 两次累加同一 double ≡ 原逐一累加 | 按位比较排除 ±0.0 边角；不对称即回退原路径 |
| J3 | 内层查表预计算：ip 与 Pd 越界位为 Pd 纯函数，子步循环不变量前置 | 表达式与求值序不变 |

任务书候选映射：「网格单调性剪枝」=J1；「内层查表预计算」=J3；「λ 表二分」= 既有
（Pg 表为索引计算非扫描，interp 已是二分）。

## 4. 小帧协议 / 1 s 拍可行性评估（只评估，不施工）

**问题**：若 DP 板内 <2 s，则 1 s 控制拍可评估（小帧 = 板侧 H1 自构造窗 + S2 FP 服务
755/755 已在固件内，下行从 13960 B 缩到 ~300 B）。

**实测结论**：**1 s 拍不可行（本代硬件/本冻结算法口径下）**。

- 加速后板内计算 = REATT 0.30 + DP 5.23 + PMS 0.004 ≈ **5.5 s/拍** —— 计算 alone
  已超 1 s 拍周期 5.5×；即使小帧把 UART 传输压到 ~26 ms（300 B@115200）也无济于事。
- DP 的 2×171×41×10 子步模拟规模是契约 §4 的冻结语义（窗口 DP 在线重规划），
  位级红线内无更优余量（J1/J2/J3 已穷尽该红线内的结构性重复）。
- **10 s 拍（契约口径）**：板内 5.5 s + UART 1.21 s = 6.7 s/拍，占空 67%，
  实时预算**满足**（证据：C3 541 拍 + C4 92 拍全链闭环 PASS）。
- UART 提速（EMS_REATT_UART_BAUD=921600，代码内既有开关）可将传输降至 ~151 ms，
  使拍墙钟 ~5.7 s（占空 57%）——产品形态阶段的候选优化，需 host 工具链同步，
  本阶段不动（C2/C3/C4 工具链冻结于 115200）。
- 小帧协议价值重估：仅在「DP 换代（近似/降阶/离线策略表）」后才有意义；
  当前口径下登记为「不必要」。
