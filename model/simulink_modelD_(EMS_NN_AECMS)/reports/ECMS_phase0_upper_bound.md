## 1. 结论摘要

以修正后的真实设备参数（电池 1071.36 kWh、充放 1050 kW、BSFC 双真实锚点 427/453 g/kWh）对 8 个场景做离线动态规划（DP）全局最优求解，与 Baseline EMS（负荷跟随）在同 BSFC 曲线、同电量维持口径下比较：

- **连续运行口径（主判定）**：8 场景节油上限 **0.50% ~ 4.22%**（P_min=400 kW 主判定配置），全部 P_min 档位平均 **2.38% ~ 4.61%**；
- **Gate 判定**：无任何场景达到 5%（GO_ROBUST 不成立）；三档 BSFC 亦未全低于 2%（NO-GO 不成立）→ **DECISION_REQUIRED**；
- **启停口径**：在当前短航程（~15 min）与启动代价参数下不优于连续口径（冷启动约定 + 怠速成本低，详见 §6.3）；
- **二维可变速扩展**：相对一维定速 −0.03 pp（合成 map 内无增量，符合构造方式预期）；
- **收益机理真实存在**：节油来源是 BSFC 曲线非线性的运行点搬移，与前两条 NO-GO 路线（功率时序优化被往返损耗锁死）机理不同；场景排序与低负荷驻留时间正相关（S02 顺水最高 4.2%，S03 逆水满载最低 2.7%，S07 桥区机动最低 0.5~1.5%）。

### 2.3 BSFC 曲线族

一维定速（1500 rpm）三档，低负荷（25%）恶化 {+30%, +50%, +70%}，pchip 保形插值，最优点 427 全域最小（无过冲自检）。28 项自检全过。**曲线形状（除两锚点外）为假定值**，三档即为此不确定性的量化。图：`results/ecms_phase0/bsfc/bsfc_1d_family.png`、`bsfc_2d_map.png`。

### 2.4 DP 求解器

- 状态 (SOC, P_prev[, on])，SOC 网格 0.005（171 点），P 网格 20 kW，Δt=1 s；后向归纳 + SOC 线性插值；
- 约束：机组 0~1000 kW（聚合）、爬坡 ≤40 kW/s、最低稳定负荷档 {0,300,400,500} kW、电池 ±1050 kW、SOC∈[0.10,0.95]；
- **终端电量维持对称带 |SOC_T − SOC₀| ≤ 0.005**；Baseline 以 k_eq=0.4774 kg/kWh 做 SOC 修正（raw/corr 双列）；
- 效率链：η_rect=η_dcdc=0.97，η_bat=0.95；
- 单实例耗时 ~0.5 s（向量化后向归纳）。

| P_min (聚合) | tier1 | tier2 | tier3 |
|---|---|---|---|

**注意 P_min=0 与 P_min≥300 之间的跳变**：P_min≥300 时 Baseline 不可行（其轨迹低于 P_min），比较方向保守（节油被低估）；P_min=0 行是严格同可行域比较。真实机组最低稳定负荷未知（待设备方确认），若实际为 30~50% 额定，相应行仍属保守估计。

**S07 tier 反转的机理**（非 bug，已独立复算验证 83.8608 kg 逐位一致）：P_min=400 kW 聚合 = 单机 L=0.4，恰好落在三档曲线的最大差异区；S07 桥区段低需求使 DP 被 P_min 约束压住，tier 越重 DP 燃油上升越快，而 Baseline 主要运行在更高负荷率段（受 tier 影响更小）。同时印证：聚合 800 kW（=单机 L=0.8）才是该曲线的高效点。

## 5. 二维可变速扩展（不进主判定）

假设机组可变速（900~1500 rpm）的合成二维 map 下，DP 节油与一维定速差 **−0.029 pp**（图 `fig_ext2d_delta.png`）。原因：二维 map 构造于一维曲线之上，min over n 在网格量化内还原一维——**合成 map 无法提供真实增量**，该扩展的价值取决于能否拿到真实万有特性数据（OQ-1/OQ-3）。

## 6. 已知局限

1. **BSFC 形状为替代假定**（仅 427/453 双锚点为真）；三档敏感性已量化其影响（±0.5~1 pp 量级）；
2. **聚合单机模型**（用户裁决 D8）：双机独立启停/出力分配是未探索自由度，GO 方向保守、NO-GO 不适用（本结论为 DECISION_REQUIRED，措辞已限定聚合口径）；
3. **启停口径的冷启动约定**：初始 on=0 强制付 C_start，短航程（~15 min）下启动代价无法摊薄（怠速 6.795 kg/h，2 kg 启动代价需停机 ~17.7 min 回本）——启停列被系统性压低，不代表长航程结论；
4. **Baseline 公平性**：节油主要体现在 SOC 修正后（DP 电量维持、Baseline 终端 SOC 漂移借电 ~3.6 kg），k_eq 折算口径已在 design §5 固定；
5. 转速准静态、无转速爬坡约束；爬坡率/最低稳定负荷/电池效率仍为假设值（待设备方确认清单）；
6. DP 为全知离线最优，是**上限**；实时 ECMS 可达比例（文献典型 60~90%）需 Phase 1 评估；
7. S01 与 S09 剖面逐位一致（PI 饱和掩盖加速差异）——场景冗余，不重复计入独立证据。

## 8. 对 Phase 1 的建议（裁决辅助材料，非结论）

**支持 GO 的证据**：
- 收益机理真实且稳定（运行点优化；全矩阵 240/240 可行、零校验失败；方向与物理预期一致）；
- 主判定口径 3.1% 均值；同可行域口径（P_min=0）达 3.6~4.6%；
- 保守偏差存在（Baseline 不可行行低估；聚合口径低估）；
- 电池容量杠杆显著（若实船电池可超配或工况含更长低负荷段，上限可过 5%）。

**支持谨慎/NO-GO 的证据**：
- 最稳健口径下无场景过 5%；S07（最具动态性的场景）上限 <1.5%；
- 实时 ECMS 只能捕获上限的一部分（文献典型 60~90%）→ 期望实际节油 ~2~3.5%；
- 结论对假定的 BSFC 低负荷形状有残余依赖（±0.5~1 pp）。

**若 GO，Phase 1 建议聚焦**：
1. 固定 λ 的 ECMS + SOC 反馈自适应（A-ECMS），以 DP 为标杆量化可达比例；
2. 优先获取真实数据消除两个最大不确定性：甲醇机分工况油耗点/万有特性、最低稳定负荷与爬坡率（向设备方索取清单见 `docs/bsfc_anchors_sources.md` 待办）；
3. 预测前瞻定位仍按 D11——先无预测，消融证明再加；
4. 场景集可瘦身：S09 与 S01 冗余，S03 满载无区分度。
