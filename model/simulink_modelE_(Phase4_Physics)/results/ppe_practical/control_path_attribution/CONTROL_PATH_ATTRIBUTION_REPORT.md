# CONTROL_PATH_INVARIANCE_ATTRIBUTION — 控制路径不变性归因报告

**问题**：冻结的正式效应估计为**退化零**（三估计量 θ̂ = 0.000 pp，CI [0,0]；48/48 航次效应为零；四臂实轨迹逐位相同）。预测源（含完美信息参考 C1）的差异在控制/执行链的**哪一层消失**？

**证据**：192 个冻结 `controller_trace_v1`、192 个植物轨迹（数组级）、冻结 t445 源码与缓存策略表、冻结可行性配置；一次小规模**控制器专用非正式探针**（§13 允许；无任何 Simulink 仿真）。

## 逐层判定（L0–L9）

| 层 | 跨臂状态 | 证据 |
|---|---|---|
| **L0/L1** ForecastWindow | **不同** | 晚期（t≥300）决策点 17,288 个：窗哈希相同数 C0vsC1=**0**、C0vsC2=**0**、C1vsC2=1,436（8.3% 偶合）；来源标识 oracle/c1_stored/live_bridge 与设计一致；C1 目标字节经导出时冻结绑定与运行时 fail-closed 校验 |
| L2 候选目标值 | 未持久化 | 冻结 runner 内部量（证据边界，如实标注） |
| **L3 选定 δλ** | **不同** | 48/48 航次数组均不相同（全时点与 t≥300 皆然）；差异决策点数 C0vsC1=948、C0vsC2=1,210、C1vsC2=603；中位最大差 0.185；C0 的 δλ 在 89% 决策点钉在下界 −0.100 |
| **L4 λ_eff** | **部分被吸收** | `λ_eff = max(0.425 + 30·(0.6−SOC) + K_S·e_hat + δλ, 0.43)`：**28.0%** 的晚期决策点在三臂中 raw-λ 均低于下限 0.43 → λ_eff 恒等于 0.43，与 δλ/e_hat 无关 |
| **L5 ECMS 动作 P_g\***（策略表） | **吸收残余** | 冻结表 `P_g(λ | Pbar, SOC 区)` 是**粗阶跃函数**：中载（640 kW）区 1 在**整条 λ 轴**（0.43–15.5）上仅 **11 个不同 P_g 动作**（边界 0.43, 0.59, 0.595, …）；10% 的表格单元平台**横跨整条 λ 轴**（最大平台宽 15.1 λ 单位）→ 残余的臂间 λ_eff 差异映射到**同一 P_g\*** |
| L6/L7 安全/PMS 前后指令 | 未持久化 | 无任何接线缺陷证据：δλ 明确进入了模型（L3 由运行元数据记录），且实轨迹逐位相同 ⇒ 被执行指令逐位相同 |
| **L8/L9 植物与 SOC** | **相同** | 48/48 航次 5 通道（SOC、双机功率、电池功率、总负载）**逐位相同，最大绝对差 = 0.0** |

**差异消失层（首个）：L4→L5**——策略表的动作量化；**次级（更早）：L4 的 0.43 下限钳位**（28% 决策点）。

## 操控核查（§4/§5）

- **C0 vs C1：操控已实现**（100% 晚期决策点窗不同）——排除 `FORECAST_MANIPULATION_NOT_REALIZED`；
- **C0 vs C2：操控已实现**（100% 不同；C2 = 冻结 Predictor-v3 经活桥，keras sha 绑定）；
- C1 vs C2 有 8.3% 决策点窗哈希偶合（两源在个别点产生相同 bin 序列），不影响结论。

## 动作敏感性（§6/§7）

- `CONTROLLER_OBJECTIVE_INSENSITIVITY`：**非主因**——DP 确实选择了不同的 δλ（L3 差异为证，DP 具选择性）；
- `ACTION_QUANTIZATION_OR_POLICY_INSENSITIVITY`：**主因**——P_g\*(λ) 的宽平台吞掉了残余 λ_eff 差异；
- `DOWNSTREAM_OVERRIDE_OR_SATURATION`：**次级**——λ_eff 0.43 下限在 28% 决策点先行吸收。

## P0 vs C0 诊断（§10）

P0（law5 SOC 自适应，无预测、无 δλ）的实轨迹与 C0（law6 Oracle）**逐位相同 48/48**——与"两者落入同一策略表动作平台与下限区"一致。**诊断性**，P0 不并入预测归因。

## 终端分类（§11/§12）

- **主机制：`ACTION_QUANTIZATION_OR_POLICY_INSENSITIVITY`**（次：λ_eff 下限饱和的部分贡献）；排除 `CONTROL_ACTION_EXECUTION_PATH_DEFECT`（无接线缺陷证据）、`FORECAST_MANIPULATION_NOT_REALIZED`（操控已证实现）、`MISSION_REGION_INSENSITIVE_TO_CONTROLLER`（任务确实经过动作敏感区外的判定以表结构为准——本报告以表平台证据为准，不主张任务侧解释）。
- **正式零结果分类：`VALID_NEGATIVE_ARCHITECTURAL_RESULT`**——操控正确、执行路径正确，冻结 C* 架构把信息差异映射为**相同的已实现动作**。
- **无需正式重跑**（§13：实现路径事实已由既有证据 + 控制器专用探针确立）；未执行任何 Simulink 仿真；未修改任何正式工件/掩码/FEC。

## 下一阶段建议（事实性）

本架构中"预测→已实现动作"的传递被两处冻结设计量级所限制：**λ_eff 下限 0.43** 与**策略表的粗动作分辨率**（中载下整条 λ 轴仅 11 档动作）。任何以测量预测信息价值为目标的后续研究，需要**其动作分辨率能使信息差异存活到执行层**的控制架构——该设计属新的前瞻性工作，需独立人工门授权。本报告不主张"预测无一般价值"，仅陈述：**在本冻结开发阶段语料与冻结实现架构内，未来信息源产生了零已实现闭环效应，且归因定位于动作量化层。**
