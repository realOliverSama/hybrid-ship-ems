## 3. 否定结论的机理解释

**节油上限被物理结构锁死（核心发现）**：C1 即时前馈在峰值等待期多发的电能并非纯损耗——它经下垂母线给电池充电，随后被负荷再利用。真正不可回收的只有 **电池充放往返损耗 fraction（约 15~20%）**。因此：

```
C2 节油上限 ≈ (C1 前馈多发能量) × (往返损耗率) ≈ 航程能耗的 0.3~0.5%
```

实测 0.293% 与该机理上限一致。2% 的过门阈值在设定时未知此分解，物理上不可达。这不是模型、参数或实现问题（τ_margin 扫描 {5,10,15,20} 全部确认：τ=10/15/20 结果差异 <0.02%，τ=5 因事件从不触发而退化）。

**场景结构的次要限制**：S04/S06 为渐进负荷，未来 60 s 窗口的峰值几乎恒位于窗口末端（t_peak_rel≈60 s 不倒数），定时机制结构性闲置，仅在离散事件（加速段、桥区机动）与航程尾部窗口截断时触发。S07 的 C1 惩罚最大（+5.27%）但 C2 几乎无改善（82.49→82.42），因为桥区机动的长等待期里前馈能量仍被电池回收利用。

## 4. t_peak 误差敏感性（T-008，FR-009）——悬崖式不对称

对 oracle t_peak 注入系统偏移 δ（δ>0 = 预测到达时间偏晚 = 启动偏晚）：

| δ [s] | Vdc_min | P_ff 激活 | Δfuel vs E2 |
|---|---|---|---|
| −20 | 707.78 ✅ | 23.3 s | +0.10 kg |
| −10 | 707.78 ✅ | 12.6 s | +0.02 kg |
| −5 | 707.78 ✅ | 6.4 s | ≈0 |
| **+5** | **689.92 ❌** | **0 s** | −0.51 kg |
| +10/+20 | 689.92 ❌ | 0 s | −0.51 kg |

**机理**：t_peak 高估仅 5 s → t_fire 晚于实际峰值 → 触发前负荷已到位 → dP≤0 → 事件在触发前被清除 → 前馈完全消失 → Vdc 保护归零。方向相反（低估 20 s）仅损失 0.10 kg 燃油且保护完好。

**工程含义**：若未来重启该机制，应对 t_peak 施加**保守负偏置**（宁可早触发）——0.1% 燃油代价购买对 +20 s 级预测误差的完全免疫。

## 5. E3 诊断（真实 MLP 幅值 + t_peak 真值 + C2）

- Vdc_min = 689.92 V = 裸 Baseline：**安全增益完全消失**
- P_ff 激活时间 265~775 s（远长于 oracle 的 7~100 s），S07 油耗 83.47 kg 反而高于 E1

**机理诊断（S04）**：Vdc_min 出现在 **t=7 s 初始加速段**（x_ship=1 m）。此时 22 s 历史窗口尚未填满（repmat 首样本填充），MLP 无法识别 t=0 的 v_cmd 阶跃 → 预测幅值/有效性不足 → 关键瞬间无前馈。t=7 s 处 MLP 预测 932.8 kW vs oracle 800 kW（+16.6%），但冷启动窗口使定时机制无法提前布局。**这不仅是"预测精度"问题，而是历史窗口冷启动的结构性盲区**。

## 6. 结论与后续选项

**按 FR-010 执行 NO-GO**：Phase 2（T-010~T-013 模型训练与部署评估）不启动。

本 Phase 的正面成果（均可直接写入论文）：
1. 定时前馈的节油上限受电池往返损耗机理约束（≤0.5%）——否定性结论本身即贡献；
2. C2 以 **1/10~1/18 的前馈激活时间**实现与 C1 **完全相同**的母线安全增益（707.78 V）——"同等安全、极小代价"的权衡结论成立；
3. t_peak 误差的悬崖式不对称敏感性与保守负偏置缓解措施（0.1% 燃油换 ±20 s 免疫）；
4. 预测冷启动盲区（t<22 s）是初始加速工况下任何历史窗口类预测器的结构性限制。

**待用户决策的方向**（见主会话汇报）：
- (a) 接受否定结论，关闭本课题（T-010~T-013 标记为不适用）；
- (b) 修订 spec 转向：研究问题从"节油"改为"安全-代价权衡 + 预测质量/冷启动敏感性"（Phase 2 重定义为提升双输出预测鲁棒性 + 保守时间偏置）；
- (c) 其他方向。
