# EMS 控制逻辑纯文本流程图

模型：HybridShip_Model_MVP（Model A 功率平衡层）/ HybridShip_ModelB_DCBus（Model B 直流母线电气层）
两模型共用同一 EMS 变体逻辑；Model B 的差异仅在底层电气层（下垂稳压），EMS 算法一致。
日期：2026-08-19（与代码 `scripts/+model/build_model*.m` 中 CODE_EMS_TARGET_B / CODE_AI_PREDICT 逐步一致）

---

## 1. Baseline EMS（传统规则门限控制，EMS_MODE=0）

```
┌────────────────────────────────────────────────────────────────┐
│ 输入（每个 0.01 s 仿真步）：P_load_total_kW, SOC                 │
│ 参数：EMS_WORK_MODE（0 手动 / 1 半自动 / 2 全自动）               │
└────────────────────────────────────────────────────────────────┘
                          │
                          ▼
              ┌───────────────────────┐
              │ EMS_WORK_MODE == 0 ?  │
              └───────────┬───────────┘
                  是 │            │ 否（半自动/全自动）
                     ▼            ▼
        ┌──────────────────┐   ┌────────────────────────────────┐
        │ P_gen_target =   │   │ P_gen_target = P_load_total    │
        │ ASSUMED_EMS_     │   │   + K_soc × (SOC_ref − SOC)    │
        │ Manual_Pgen_kW   │   │ （负荷跟随 + SOC 滞回修正）     │
        │ = 400 kW（定值） │   │ K_soc=200 kW/SOC, SOC_ref=0.60 │
        └────────┬─────────┘   └───────────────┬────────────────┘
                 │                             │
                 └──────────────┬──────────────┘
                                ▼
                ┌───────────────────────────────┐
                │ 限幅 [0, Gen_P_max=1000 kW]   │
                └───────────────┬───────────────┘
                                ▼
                ┌───────────────────────────────┐
                │ 06 发电机平均模型（物理约束）： │
                │ 爬坡 ±40 kW/s → 一阶惯性 5 s  │
                │ → 限幅 [0, 1000] kW           │
                └───────────────┬───────────────┘
                                ▼
                          P_gen_actual
                                │
        ┌───────────────────────┴────────────────────────┐
        │ Model A：电池吸收残差 P_bat = P_load − P_gen      │
        │ Model B：电池 DC/DC 下垂稳压（独立于 EMS）：      │
        │   P_bat = K_droop·(750 − V_dc)，K_droop=10 kW/V │
        │   母线：C·V·dV/dt = η_rect·P_gen + P_bat − P_load│
        │   欠压降额：V_dc<675 V 时推进功率线性降额至 600 V │
        └─────────────────────────────────────────────────┘

规则性质：EMS 只发功率参考值；母线稳定由底层变换器（下垂）保证——
即使 EMS 完全失效，母线电压仍由电池下垂维持（符合 CCS 2026
"系统稳定性不能完全依赖 PMS/EMS"的要求）。
异常处理：任何设备异常只产生报警信号，不强制切换 EMS 工作模式。
```

## 2. AI 预测增强 EMS（EMS_MODE=1 且 EMS_WORK_MODE=2 全自动）

```
┌────────────────────────────────────────────────────────────────┐
│ 输入：P_load_total, SOC, v_cmd, v_ship, accel, x_ship, t        │
└────────────────────────────────────────────────────────────────┘
                          │
          ┌───────────────┴────────────────┐
          ▼                                ▼
┌──────────────────────┐      ┌────────────────────────────────┐
│ 支路 A（规则基值）：  │      │ 支路 B（预测前馈，1 Hz 环内推理）：│
│ P_base = 与 Baseline  │      │ 滑动窗口（22 s × 5 通道）        │
│ 完全相同的规则门限     │      │ [P_load, v_cmd, v_ship,        │
│                      │      │  accel, x_ship]                │
│                      │      │   ↓ z-score 归一化              │
│                      │      │   ↓ MLP 110→64→32→1            │
│                      │      │   ↓ ΔP̂ = max(预测增量, 0)        │
│                      │      │ P_pred_max = P_load + ΔP̂       │
└──────────┬───────────┘      └───────────────┬────────────────┘
           │                                  ▼
           │                  ┌────────────────────────────────┐
           │                  │ 有效性门控（全部满足才放行）：   │
           │                  │  ① MLP_WeightsLoaded == 1       │
           │                  │  ② 输入/输出全部为有限值         │
           │                  │  ③ 0 ≤ P_pred ≤ 2000 kW         │
           │                  │ 任一不满足 → P_ff = 0           │
           │                  │   （自动退回 Baseline 行为）     │
           │                  └───────────────┬────────────────┘
           │                                  ▼
           │                  P_ff = min(K_ff × max(P_pred − P_load, 0),
           │                             FF_Max = 400 kW)
           │                                  ▼
           │                  P_ff' = P_ff × (EMS_WORK_MODE==2)
           │                                  │（非全自动 → P_ff'=0）
           ▼                                  ▼
┌──────────────────────────────────────────────────────────────┐
│ P_gen_target = max(P_base, P_load_total + P_ff')              │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
           与 Baseline 完全相同的后段：
           限幅 [0, 1000 kW] → 发电机爬坡/惯性/限幅 → P_gen_actual
                           │
                           ▼
        底层（Model B）：电池下垂稳压 + 母线电容 + 欠压降额
        （与 Baseline 共用同一物理对象与安全边界）

设计要点：
- 预测只影响"提前量"（前馈），不突破任何物理限幅；
- AI 失效（无权重/越界/非有限值/非全自动模式）→ P_ff=0 → 严格退回
  Baseline（已验证：ΔP_gen = 0）；
- 预测器输入全部是当前/历史观测量，不使用未来真实负荷（无理想预测器）。
```

## 3. 两种逻辑的关系（一图总结）

```
                 ┌──────────────────────────────┐
                 │   上层 EMS（秒级决策）         │
                 │                              │
                 │  Baseline: 负荷跟随+SOC修正    │
                 │  AI: Baseline + 预测前馈       │
                 │     （可失效 → 自动回退）       │
                 └──────────────┬───────────────┘
                                │ P_gen_ref（功率参考值）
                                ▼
                 ┌──────────────────────────────┐
                 │   底层控制（毫秒~秒级，自治）   │
                 │                              │
                 │  发电机：爬坡/惯性/限幅         │
                 │  电池 DC/DC：下垂稳压          │
                 │  母线：电容积分                │
                 │  逆变器：欠压降额              │
                 └──────────────────────────────┘
        CCS 2026 原则：稳定性由底层保证，EMS（含 AI）只做上层优化。
```
