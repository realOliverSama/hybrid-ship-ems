## 1. v1 生成器的随机维度分析（问题定位）

`ecms2.voyage_generator` 的随机性仅有两处：

1. 中间段序列：3~6 段，从 {港区, 经济, 赶班, 桥区, 逆水} 有放回抽取（逆水 ≤1 段/航次）；
2. 各段时长：段型区间内连续均匀（如经济段 10~25 min）。

其余全部**固定**：

| 段型 | 速度 (kn) | 水流 (m/s) |
|---|---|---|
| 离泊 depart | 3（固定） | 0（固定） |
| 港区 harbor | 5（固定） | 0（固定） |
| 经济 eco | 8（固定） | 0（固定） |
| 赶班 rush | 11（固定） | 0（固定） |
| 桥区 bridge | 5（固定） | 0（固定） |
| 逆水 upstream | 11（固定） | −1（固定） |
| 靠泊 berth | 3（固定） | 0（固定） |

推论：**同一段序列的航次，其速度剖面形状完全相同**（仅段边界位置/总时长缩放不同），
推进功率 `P ∝ k·V_rel³` 也完全相同。对预测器而言，v1 的 200 个航次实际是
"有限个模板 × 时长缩放"的族——这正是外部评审指出的 **模板级近重复（template-level
leakage）** 风险的根源，也是 Phase 2 模型跨航次泛化不足（val RMSE 9.303 kWh、
R²≈0.73）的数据侧成因。

v2 的设计目标：**在不改变 7 类段型语义、不引入海况/波浪、保持完全确定性可复现的
前提下，把"模板"参数化为连续工况空间。**

## 2. 约束（不可协商，来自 AGENTS.md / 用户裁决 / spec）

1. 不引入海况、波浪、风等海洋扰动机制（用户 2026-08-28 否决；本船为内河船）。
2. 船体阻力物理形式不变：`R_hull = k_res · Hull_K_R · V_rel·|V_rel|`，
   `F_env_const = 0`；扰动只能通过**已有通道的取值多样化**实现，不得改公式。
3. 7 类段型集合与语义保持不变（工况识别器标签来源稳定，FR-310 / OQ-3）。
4. 装备边界不动：Mot_P_nom=700 kW（聚合）、hotel=100 kW、P_SAT_KW=800、
   预检 P_limit=850 kW、逆水段 ≤1 段/航次、总时长 60~120 min。
5. 全程单随机流（`rng(seed,'twister')`）、新种子、同种子两次生成逐位一致。
6. v1 生成路径行为逐位不变（v1 种子回归断言）。
7. 泄漏纪律沿用 FR-302（航次级 split、窗口不跨航次、fit-on-train、test 零参与、
   S20/S01/S02/S07 结构性隔离）。

## 3. 预检数学基础（v2 参数范围的推导依据）

效率链 `eta = 0.97·0.95·0.60·0.97 ≈ 0.5363`，`Hull_K_R = 1780`。

需求功率（送达口径）：`P_calc(kW) = k_res · Hull_K_R · V_rel³ / eta / 1000`，
`V_rel = v_ship − v_current`（逆水段水流为负 → V_rel = v + |current|）。

两个关键阈值：

- **非饱和上限**：P_calc = 700 kW → V_rel = (700·536.3/1780)^(1/3) ≈ **5.95 m/s ≈ 11.56 kn**。
- 预检 850 kW 上限在 v1.1 送达口径下（`min(P_calc, 700) + 100`）恒为 800 kW，
  **功率分支实际不再触发拒绝**（v1 语义：速度饱和 ≠ 降额，S20 段 9 已验证逆水
  800 kW 持续饱和零降额）。v1 中拒绝仅来自时长越界与逆水段计数。

v2 需要一条**新的、有物理意义的拒绝规则**（见 §4 M0），否则速度随机化会产生
大量饱和航次（船速保持不住、段语义失真、y 分布出现 clipped 质量）。

v1 校验（对照）：rush 11 kn（V_rel=5.66）→ P_calc ≈ 602 kW，不饱和 ✓；
upstream 11 kn + 1 m/s（V_rel=6.66）→ P_calc ≈ 986 kW → 饱和送达 800 kW（v1 既有语义）。

**注（饱和语义）**：硬规则（见 M0）适用于**非逆水段**——v2 舰队非逆水段全程
不饱和；逆水段允许饱和（v1 既有语义，S20 段 9 先例：800 kW 持续饱和、零降额），
饱和深度由 V_rel ≤ 7.06 m/s 包络约束，与 v1 饱和段（V_rel=6.66）同族。
v1/v2 逆水段语义一致，无分布断层。

## 4. 扰动机制清单（提议）

### M0（拒绝规则，非扰动）硬规则（用户裁决 2026-08-28，澄清后定稿）

1. **非逆水段**：`P_calc = k_res · Hull_K_R · V_rel³ / eta / 1000 > 700 kW`
   ⇒ 整航次拒绝重抽（饱和样本不进入 v2 非逆水段）；
2. **逆水段**：**允许饱和**（v1 既有语义，S20 段 9 先例），但约束包络
   `V_rel ≤ 7.06 m/s`（角落组合由拒绝采样裁剪，见 M1/M2）；
3. 时长越界、逆水段计数规则不变；
4. 实现时与 v1 回归断言共存：v1 路径不经过 v2 预检（分离函数），互不干扰。

非逆水段等价包络：V_rel ≤ (700·536.3/1780)^(1/3) ≈ 5.95 m/s（≈11.56 kn，
含弱流影响）。逆水段包络 V_rel ∈ [5.74, 7.06] m/s（v1 的 6.66 位于其中）。

### M1 段型速度随机化（主机制）

| 段型 | v1 固定 | v2 范围 (kn) | 依据 |
|---|---|---|---|
| depart | 3 | [2.5, 3.5] | 离泊操纵速度受泊位/拖轮影响 |
| harbor | 5 | [4.5, 5.5] | 港区限速上限固定、实际航速可变 |
| eco | 8 | [7, 9] | 经济航速随班期压力/吃水变化 |
| rush | 11 | [10, 11.5] | 上限受 M0 拒绝规则与弱流联合约束（11.56 kn 为非饱和物理上限） |
| bridge | 5 | [4.5, 5.5] | 桥区限速同港区 |
| upstream | 11 | [10, 11.5] | 与 M2 水流联合包络 V_rel ≤ 7.06 m/s（饱和允许，v1 语义一致） |
| berth | 3 | [2.5, 3.5] | 同离泊 |

物理依据：内河服务航速并非定值——班期压力、吃水/载况、船长习惯都会使同一段型
以不同航速执行。`P ∝ V_rel³` 使该机制成为功率/能量多样性最大的来源：

- eco 7→9 kn：推进功率 155→330 kW（±35% 围绕 v1 的 232 kW）；
- rush 10→11.5 kn：452→689 kW（v1 固定 602 kW）。

### M2 水流幅值/方向扩展

| 段型 | v1 | v2 范围 (m/s) | 依据 |
|---|---|---|---|
| upstream | −1（固定） | −[0.6, 1.2] | 长江枯/洪期流速变化；与 M1 联合包络 V_rel ∈ [5.74, 7.06]，P_calc 630~1169 kW，送达 730~800 kW（不饱和/饱和自然混合） |
| 其余段 | 0（固定） | [−0.3, +0.3] | 长江弯曲河段顺逆不定；符号约定与现模型一致（+为顺水，减小 V_rel） |

物理一致性：水流为航道属性，时间常数远大于段长 → **段内恒定、跨段可变**
（沿用现有 `current_time_s/current_value_mps` 段级路点机制，无需改模型）。
rush 段弱流与 M0 拒绝规则联合作用（如 11.5 kn + 逆向 0.3 m/s 将被拒绝重抽），
由 draw_attempts 统计监控拒绝率。

### M3 阻力乘子多样化（水位/吃水/污底等效）

- 航次级 `k_res ∈ [0.95, 1.15]`（航次内恒定）：季节水位、吃水变化、污底的
  航次间差异；对 P 线性（±10~15%）。
- **实现通道（决策点，见 §7-D3）**：现 harness 无逐航次阻力变量（阻力是场景级
  通道）。提议为模型新增一个标量输入通道 `VOYAGE_RESISTANCE_MULT`（默认 1.0，
  缺省时行为与现状逐位一致），走既有 VOYAGE_* 注入模式。这是**模型结构小改**，
  须走 02_build_model + 结构差异检查 + 03_run_smoke_tests 流程。
- 段级浅水阻力带（浅滩段 +10%）：**v2.0 暂缓**，若 T-302 后 K-shape 审计显示
  覆盖仍不足再立项（避免一次引入过多维度难以归因）。

### M4 段内避让速度台阶（**已删除**）

**用户裁决（2026-08-28）：M4 从主数据集删除。** 不实现段内路点细分与避让台阶；
7 类段型内速度恒定的段语义保持。若未来需要可重新立项，但当前 Phase 2.5 主线
不含该机制（tasks T-302 实现清单中无此项）。

### 明确不做（本版）

- **段内避让台阶 M4（用户裁决删除，2026-08-28）**；
- 海况/波浪/风（用户否决）；
- 环境随机噪声过程（保持全确定性）；
- 新增段型（7 类保持）；
- 加/减速率随机化（保持 0.15/0.05）；
- hotel 负荷随机化（保持 100 kW）；

## 5. N 规模与数据集划分（OQ-1 后半）

- **N = 400**（v1 200 → v2 400）。
  理由：速度/水流/阻力三个连续维度进入后，单航次成为连续工况空间中的一个采样点，
  需要更多航次保证 train/val/test 分布一致性，并为 FR-316 近邻重复审计提供可信的
  split 内/间距离分布；200 航次在三维连续扰动下存在 split 间协变量漂移风险。
- 窗口量估算：v1 200 航次 → 77,586 窗口（≈388/航次）；v2 ≈ **15.5 万窗口**，
  TCN 规模训练成本仍低（单卡分钟级/epoch）。
- 航次级 split：**280/60/60**（保持 v1 的 70/15/15 比例，v1 为 140/30/30）。
- 新种子提议：**20260829**（与 v1 的 20260825 区分）。
- S20/S01/S02/S07 结构性隔离不变（不进入 fleet split，仍为独立判定/消融场景）。
- 每个航次的扰动参数（各段速度/水流/k_res/避让台阶）**全部写入 manifest**——
  同时服务于 FR-316 近邻审计与 FR-310 工况标签追溯。

## 6. 对 y 分布影响的预估

y = 未来 300 s 电池净能量（kWh）。v1 中 y 的可变性主要来自段组合与段时长；
v2 叠加：

| 维度 | 变化幅度（对 P 的影响） |
|---|---|
| M1 速度 | eco ±35%、rush −25%/+14%（相对 v1 固定值） |
| M2 水流 | 逆水段 P_calc 630~1169 kW（送达 730~800，不饱和/饱和混合）；弱流使非逆水段 P 再偏移 ±10~20% |
| M3 k_res | 线性 ±15%（与 M0 规则交互：高 k_res 使 rush 有效上限下移，拒绝采样自然处理） |
| M4 | 已删除（用户裁决） |

综合预估：y 分布展宽约 **±25~35%**，并消除 v1"同段序列航次 y 几乎相同"的简并；
逆水段饱和语义与 v1 一致（送达上限 800 kW），非逆水段无饱和（无非逆水
clipped 质量）。
风险：M0 硬规则 + 时长约束叠加可能推高重抽率（v1 平均 1.x 次/航次；逆水段组合
理论接受率 ≈87%），T-302 须报告 draw_attempts 分布；若拒绝率异常（>3 次/航次均值），
按 Escalate 返回主 Agent 调整范围，不得静默放宽 M0。
