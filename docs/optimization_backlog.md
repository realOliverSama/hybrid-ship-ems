## 1. 挂起原则（先读这个）

Phase 2 的机器判定为 **PARTIAL**（nn_oracle_capture = 0.3704 ∈ [0.30, 0.50)），C4 捕获 oracle 增量的 **37%**，未达 ≥50% 合格线。但这**不等于预测路线失败**——它只说明"纯历史外推 + 保守低增益通道"在当前精度上限下能捕获这么多。

**挂起的工程纪律**（2026-08-26 凌晨②裁决）：

> 不及预期的指标**不在缺省/估计参数上硬调**。BSFC 低负荷形状（±0.5~1 pp）、最低稳定负荷、爬坡率等仍为假设值（`docs/data_request_list.md` 待设备方确认），在这些"假目标"上调优 NN 参数可能产生虚假收益且不可辩护。

因此所有优化方向先列入本 backlog，**待真实船舶/机组参数到位后按优先级重启**。任何重启动作须回到本文件走修订流程（AGENTS.md §19：优化假目标 > 暂时好看）。

## 2. 当前性能基线（PARTIAL 的构成）

| 指标 | 数值 | 含义 |
|---|---|---|
| nn_oracle_capture | **0.3704** | (C2−C4)/(C2−C3)，S20 复合航次 |
| C4 vs C2 增量 | **+0.60 pp** | 5.26% → 5.86%（真实收益） |
| oracle 增量（上限） | +1.63 pp | C2→C3（全知未来，不可实时实现） |
| 留出泛化 median | **−0.232%** | 4/10 航次为正，其余为负（收益依赖航次结构） |
| S07 桥区机动 | **−1.2 kg 恶化** | 失败模式（见 §4） |
| 预测精度 | RMSE 9.30 kWh, R²≈0.73 | 约 27% 未来能量方差不可由历史 300 s 解释 |

**收益天花板的物理解释**：预测目标是未来 300 s 总能量 Ê_H，而船舶功率的随机分量（浪、流扰动）在历史窗口中不可见，R²≈0.73 是纯历史外推的**理论上限**，不是模型没调好。

## 3. 候选优化方向（按预期收益/成本排序）

每条含：描述、预期收益来源、依赖条件、优先级、评估方法。

### B1 — 航次计划类特征（最高预期收益）

- **描述**：当前输入 = 历史 300 s P_demand + v_ship + accel（302 维，纯历史外推）。加入**航次计划特征**（未来速度计划 v_plan(t+1..t+H)、航段类型 one-hot、剩余航程），让 NN 看到"即将进入桥区限速段"这类可计划信息。
- **预期收益来源**：报告 §6.3——R²≈0.73 的 27% 残差中，相当一部分是"可计划但未提供"的信息（航段切换点、速度计划变更）。若航次计划可得，capture 预期显著提升。
- **依赖**：航次计划数据来源（航线设计/电子海图/调度系统）；需要重新生成含计划特征的 fleet 数据集并复训。
- **优先级**：**P0**（若航次计划数据可获取，这是唯一能突破 R² 天花板的方向）
- **评估方法**：重训 MLP（输入维度扩展），gate 复跑，capture 是否过 50%；留出航次泛化是否转正。
- **风险**：航次计划数据可能不可得（船舶实际运行中不一定有精确未来速度计划）；若不可得，B1 自动失效。

### B2 — 失败模式门控（S07 类场景保护）

- **描述**：S07 桥区机动场景 C4 恶化 1.2 kg（长时低功率段 + 突发操纵，NN 按平均能量预测导致 SOC_ref 系统性偏移方向错误）。加**场景分类门控**：检测到桥区/操纵工况时切换回 C2（规则 A-ECMS）或对 C4 输出加下限保护。
- **预期收益来源**：消除负收益场景，留出泛化 median 从 −0.232% 向正迁移。
- **依赖**：场景分类器（可由 v_ship 变化率 + P_demand 方差在线检测）；或人工切换逻辑。
- **优先级**：**P0**（用户裁决已明确：Phase 3 立项时需包含 S07 类失败模式的门控保护设计）
- **评估方法**：S07 场景 C4+门控 vs C2 对比；留出航次 median 是否转正。
- **备注**：这是**安全/鲁棒性**改进，不是收益提升，但它是 C4 上船的前置条件。

### B3 — 预测入环方式（低增益通道 → 更直接）

- **描述**：当前预测经 SOC_ref 前瞻通道注入（`SOC_ref_eff = SOC_ref + K_S·ê`，K_S=0.01 保守增益）。探索更直接的入环方式：
  - (a) 提高 K_S（更大胆的 SOC 偏移）；
  - (b) 预测直接调制 λ（λ_eff = λ₀ + K_soc·(SOC_ref−SOC) + K_pred·ê）；
  - (c) 预测驱动 DP 前瞻窗的局部重优化（ MPC-lite）。
- **预期收益来源**：当前保守通道放大了"低估偏向"（under_freq=0.426）的负面影响；更直接的入环可能更好地利用有限的预测信息。
- **依赖**：需要重新标定 K_S/K_pred；评估过冲风险（SOC 出带）。
- **优先级**：**P1**（收益方向不确定——提高增益可能同时放大 S07 类失败模式）
- **评估方法**：K_S 敏感性扫描（0.005/0.01/0.02/0.05），观察 S20 capture 与 S07 恶化的权衡。
- **风险**：与 B2 耦合——若先做 B2 再做 B3，门控可兜住过冲风险。

### B4 — 预测时域（300 s 窗口调优）

- **描述**：当前预测时域 H=300 s（5 min）。探索 H ∈ {120, 180, 300, 600} s 的权衡：更短时域精度更高但前瞻不足；更长时域前瞻充分但精度下降更快。
- **预期收益来源**：报告 §2——Ê_H 的归一化 σ 随时域增长，信噪比恶化存在最优时域。
- **依赖**：重新生成不同 H 的训练数据；复训。
- **优先级**：**P1**（中等预期收益，工程量小——只需改数据生成与输入维度）
- **评估方法**：多 H 值训练对比 val RMSE 与 capture 的相关性。

### B5 — 换预测模型（LSTM / 多步概率 / Transformer）

- **描述**：当前 MLP 302-128-64-1（47k 参数）。候选：
  - (a) LSTM（已在 N=80 对照中完败，val RMSE 10.68 vs 10.17，但 fleet-200 复训后未重试）；
  - (b) 多步概率预测（输出未来 300 s 能量分布而非点估计，供控制器做风险敏感决策）；
  - (c) 轻量 Transformer（注意力机制可能更好地捕捉航段切换）。
- **预期收益来源**：模型容量/结构差异；但 R²≈0.73 的天花板主要是数据驱动的，换模型预期收益有限。
- **依赖**：(b) 需重新定义预测目标与损失函数（分位数回归/负对数似然）；(c) 需更多数据。
- **优先级**：**P2**（预期收益最低，但 Phase 3 的 N6 算力笔记显示 NPU 算力大量闲置，若未来需要更复杂模型可作为技术储备）
- **评估方法**：同数据集同划分训练对比；仅当 val RMSE 显著优于 MLP（>5%）才值得进 Simulink 集成。

### B6 — 数据规模与多样性（fleet 扩展）

- **描述**：当前 fleet-200（N=200 航次，77,586 窗口）。探索 N=400/600 的规模红利；或增加更多极端工况（更大风浪、更复杂的靠离泊序列）。
- **预期收益来源**：N=80→N=200 已有 +8.5% 数据红利（val RMSE 10.17→9.30）；但边际收益递减。
- **依赖**：更多计算资源（parsim 已修复可并行）；更多样化的场景积木。
- **优先级**：**P2**（低预期收益，但成本也低——可作为其他方向的配套）
- **评估方法**：N=400 训练对比 val RMSE 改善幅度；若 <3% 则停止扩规模。

## 4. S07 失败模式（Phase 3 前置）

S07 桥区机动的 C4 恶化是**当前唯一明确的负收益场景**，也是 C4 上船的**安全红线**：

| 属性 | 内容 |
|---|---|
| 场景 | S07 桥区机动（长时低功率段 + 突发操纵） |
| 表现 | C4 比 C2 多耗 1.2 kg（fuel_corr 恶化） |
| 机理 | NN 按平均能量预测，SOC_ref 偏移方向错误（低估偏向在该场景有害） |
| Phase 3 要求 | 用户裁决：门控保护设计必须纳入 Phase 3 立项 |
| 对应 backlog | B2（门控）是 P0，与 B3（入环方式）耦合 |

## 5. 重启条件

任何 backlog 项重启须同时满足：

1. **真实参数到位**：`docs/data_request_list.md` 中的关键项（最低稳定负荷、爬坡率、分工况油耗点、电池效率）至少 50% 已从设备方获取并落模；
2. **评估方法明确**：重启前先写 mini-spec（预期收益、评估场景、gate 阈值），走 brainstorm → requirements 门禁；
3. **优先级确认**：按本文件优先级排序，高优先级未做不跳低优先级；
4. **不碰假目标**：若重启涉及 BSFC 形状/最低稳定负荷等假设值，先确认该参数已用真实值替换。
