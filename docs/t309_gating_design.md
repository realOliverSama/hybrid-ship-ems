# T-309 门控设计文档：失败模式门控（FR-311）+ G0~G3 消融协议

- 任务：T-309（主 Agent 设计门，无代码）
- 需求：FR-311、FR-312、FR-315、FR-317、FR-318
- 状态：主 Agent 拟定并批准（用户 2026-08-30 指令"跑到 310 给我决策"，授权主 Agent 代行批准门）
- 下游：T-310 按本文档集成（Simulink 脚本驱动）

## 1. 设计目标与原则

预测通道（NN 能量预测 ê_H）在两类失败模式下不可信：
1. **分位数发散**：q90−q10 不确定性过大（分布外/扰动窗）；
2. **危险工况**：桥区/靠离泊/逆水等受限机动段（预测通道训练分布中样本稀少，
   且真实语义为"功率受限/机动优先"，规则通道更可靠）。

原则：**确定性、可单元测试、最小复杂度**（v1.1：能用简单机制解决就不部署第二个
网络）；门控只作用于 NN 通道增益，绝不触碰 law=4/5/6 规则内核（Escalate If 红线）。

## 2. 增益语义（与 law 框架的接口）

NN-A-ECMS（law=7）中，NN 通道输出 ê_H 进入成本项。门控即对该通道乘以
增益 K ∈ [0, 1]：

    ê_gated = K · ê_H

- K = 1：通道全开（G0 语义）；
- K ∈ (0, 1)：通道降权，规则通道相对权重上升；
- K = 0：NN 通道静默，等价回退 **law=5**（规则 A-ECMS）语义；
  ê_H 仍计算但不进入成本（对应 law=6 的 ê=0 观测口径，二者实现取一，见 §5）。

## 3. G1：分位数门控（确定性分段线性）

输入：q10(t)、q90(t)（去归一化 kWh）；宽度 s(t) = q90 − q10。

    K_q(t) = 1                              , s ≤ S1
           = (S2 − s) / (S2 − S1)           , S1 < s < S2
           = 0                              , s ≥ S2

阈值固定来源：**val split 上 s 的 P75 与 P95**（S1=P75, S2=P95），写入常量文件，
**禁止用 test/S 场景调参**（FR-318/诚信纪律）。

## 4. G2：工况门控（识别器 + 类别映射 + 迟滞）

输入：T-308 识别器输出（7 类 softmax）。

类别映射（确定性）：
- 受限/机动类 {depart(1), bridge(5), upstream(6), berth(7)} → K_w = 0（回退 law=5）；
- 常规类 {harbor(2), eco(3), rush(4)} → K_w = 1。

**迟滞机制**：类别切换需**连续 m=3 个窗口**（30 s）输出同一新类别方可生效，
防止边界抖动；切换期间保持上一有效状态。实现为纯函数状态机（上一状态作为
输入显式传入，无隐藏状态，可单测、可复现）。

## 5. G3：组合门控

    K(t) = K_q(t) · K_w(t)

（两门取乘积 = 最保守者生效；K=0 时回退 law=5 语义，与 G1/G2 单门一致。）

## 6. 回退语义与 law 接口

- 门控增益 K 以常量向量/信号注入 law=7 成本计算（脚本驱动，SimulationInput 可设）；
- K=0 的实现口径：ê_H·K=0 进入成本（保留 law=7 结构，减少新代码路径）；
  其行为等价性（与 law=5 纯规则结果一致）由单测 §7.4 断言；
- 门控参数（S1/S2/m/类别映射）全部为 cfg 常量，不引入运行时可变状态。

## 7. 单测方案（沿 test_ecms_law 模式，纯函数）

1. **K_q 单调性**：s 递增时 K_q 非增；边界值 S1/S2 精确命中 1 与 0；
2. **类别映射**：7 类输入 → 期望 K_w（含 softmax 无关性——只看 argmax 类别）；
3. **迟滞**：单窗/双窗的新类别不改变状态；连续 3 窗才切换；切回同样需 3 窗；
4. **回退等价性**：K≡0 时 law=7 输出与 law=5 在同一场景逐位一致（或声明容差内一致）；
5. **G3 组合**：K = K_q·K_w，任一为 0 则为 0。

## 8. G0~G3 消融协议（T-310 必跑）

| 配置 | 分位数门控 | 工况门控 | 说明 |
|---|---|---|---|
| G0 | ✗ | ✗ | 纯预测通道基线（= Phase 2.5 现状） |
| G1 | ✓ | ✗ | 单机制：分位数 |
| G2 | ✗ | ✓ | 单机制：工况识别（T-308 识别器） |
| G3 | ✓ | ✓ | 组合 |

场景集（判定口径 D4 不变）：
- **S20** benefit 判定（capture 指标）；
- **S01/S02/S07** 消融（S07=回退场景，重点观察门控是否消除其失败模式）；
- **≥10 留出航次** non-degradation 门禁（FR-318：零新增降额、零 SOC 越限、
  节油差 median ≥ −0.5%、min ≥ −1.5%）。

**决策规则（FR-317③ 前置）**：
- 工况识别器进入最终架构 ⇔ G2/G3 相对 G1 满足全部：
  (a) S07 回退失败模式消除；(b) S20 capture 不显著损失；(c) 留出门禁通过；
- 否则最终形态 = Predictor + G1 分位数门控 + A-ECMS（识别器降级为备案）。
