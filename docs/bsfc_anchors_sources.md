## 引用口径说明

- 427 与 453 均为**甲醇质量消耗率**（非柴油当量）；比较或换算时须使用甲醇 LHV ≈ 19.9 MJ/kg。
- 两点差异（453 vs 427，约 6%）符合"额定点略偏离最优点"的典型规律；最优点负荷率位置（设计假定 80% 额定）为 design 假定值，见 `.specs/adaptive-ecms-methanol/design.md` §3.1。
- 低负荷区曲线形状无真实数据，按 requirements FR-004 以 {+30%, +50%, +70%} 三档恶化做敏感性——**论文引用时一维曲线形状不得表述为厂家数据**。
